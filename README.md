# Cold War Simulator
An educational, turn-based Cold War strategy simulation built in Python using Pygame, designed as a digital replacement for a pen-and-paper classroom game used by my former high school history teacher, and built to his specifications.

The goal of the game is to model geopolitical tension, proxy conflicts, escalation, and decision-making during the Cold War in an interactive, replayable format suitable for classroom use.  It contains 'Event Cards' that pop up with educational information for students to learn about real-life Cold War events throughout the course of the game, and to learn about not only the stakes of the conflict, but the difficulty and restraint it took to not blow up the world.
